# Style Studio v0.4

## Changes

- Centers reference images on load.
- Reset View now fits and centers the image.
- Mouse wheel zooms around the cursor.
- Middle mouse drag, Shift + drag, or Alt + drag pans the canvas.
- Landmark markers remain readable while zooming.
- Landmark markers can be dragged after placement.
- Double-click a marker to delete it.
- Adds landmark progress count and current step indicator.
